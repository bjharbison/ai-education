Master Glossary

56 terms spanning semiconductor fabrication, HBM, AI hardware, GPU software stacks, machine learning, and geopolitics.

AI agents / tool use
LLM systems operating in observe-reason-act loops, calling external tools via function calling (structured JSON output). Core challenge: reliability over multi-step tasks. LangChain (rapid prototyping), LlamaIndex (document RAG), DSPy (prompt optimisation) are major orchestration frameworks.
ArF / EUV
ArF: argon fluoride laser (193 nm) used in immersion lithography. EUV: extreme ultraviolet (13.5 nm) generated by tin-droplet plasma in vacuum. Only ASML manufactures EUV tools (~$380M each). Required for sub-7nm patterning.
Arithmetic intensity / Roofline
Arithmetic intensity = FLOPs per byte of memory traffic. Roofline model: below ridge point (peak FLOPs ÷ peak BW) → memory-bound; above → compute-bound. H100 ridge: ~295 FLOP/byte. LLM inference at batch=1: ~1–5 FLOP/byte — GPU compute is >95% idle.
Autograd
PyTorch's automatic differentiation engine. Records operations in a dynamic computational graph; .backward() applies the chain rule in reverse to compute gradients. Without autograd, manually deriving and implementing gradients for every architecture would be impractical.
BEOL
Back End of Line — the fabrication phase where copper metal interconnect layers are deposited and patterned to wire transistors into circuits. Modern chips have 12–18 BEOL metal layers fabricated by the damascene process.
BERT vs GPT
BERT: encoder-only, bidirectional attention, masked language model training — best for classification and understanding tasks. GPT: decoder-only, causal attention, next-token prediction — scales to trillion+ parameters, enables in-context learning, dominates generation tasks.
BIS / Export controls
US Bureau of Industry and Security restricts advanced chip exports. Oct 2022: blocked A100/H100 to China (compute/bandwidth thresholds). Oct 2023: tightened to catch A800/H800. Goal: maintain 2–3 generation compute gap. Effectiveness limited by transshipment and domestic Chinese chip development.
CANN
Compute Architecture for Neural Networks — Huawei's CUDA equivalent for Ascend processors. Includes ACL for kernel programming, PyTorch-Ascend adapter, HCCL for multi-chip communication. Primary AI compute option in China following US export controls on H100/A100.
CHIPS Act
Creating Helpful Incentives to Produce Semiconductors (US, 2022): $52.7B manufacturing subsidies + $24B tax credits. Recipients: TSMC Arizona, Intel Ohio, Samsung Texas, Micron Idaho. EU Chips Act: €43B. Meaningful US volumes by 2027–2028; full ecosystem parity is multi-decade.
CMP
Chemical Mechanical Planarization — wafer polishing using abrasive slurry to achieve atomic-level surface flatness. Used after each metal layer, after TSV copper fill, and for die thinning. Controls dishing and erosion to sub-30 nm tolerances.
Continuous batching / PagedAttention
vLLM (2023): continuous batching inserts new requests as slots free (vs waiting for whole batch). PagedAttention manages KV cache in non-contiguous physical pages like OS virtual memory. Together: 10–20× throughput improvement over naive serving.
CoWoS
Chip on Wafer on Substrate — TSMC's advanced packaging platform mounting GPU die and HBM stacks on a silicon interposer. H100 interposer: ~800 mm². Variants: CoWoS-S (full silicon), CoWoS-R (RDL interposer).
CPU vs GPU
CPU: few powerful latency-optimised cores — ideal for sequential, branchy code. GPU: thousands of simple cores — ideal for data-parallel workloads like matrix multiplication. Neural network training is maximally data-parallel.
CTE mismatch
Coefficient of Thermal Expansion mismatch between copper (17 ppm/°C) and silicon (2.6 ppm/°C). Causes stress in TSV-silicon interface under temperature cycling; shifts transistor threshold voltages within 8–15 µm keep-out zone.
cuBLAS / cuDNN / NCCL
cuBLAS: optimised BLAS (matrix multiply) using tensor cores automatically. cuDNN: deep learning primitives (convolutions, attention, normalisation). NCCL: collective communication (allreduce, allgather) for multi-GPU training. The invisible infrastructure under every framework.
CUDA kernel
Function running on GPU with a grid of thread blocks. Each thread processes one data element; threads in a block share SM's fast shared memory (228 KB). Warps of 32 threads execute in lockstep (SIMT). GPU hides memory latency by switching warps.
Damascene process
IC wiring method: etch trenches into dielectric, fill with copper, planarize by CMP. Single damascene: lines or vias separately. Dual damascene: both in one step. Standard for all modern BEOL and interposer RDL.
DCGM
Data Center GPU Manager — NVIDIA's fleet-scale telemetry daemon. Polls all GPUs, runs diagnostics, exports Prometheus metrics via dcgm-exporter. Key HBM field IDs: 1004 (SBE volatile), 1005 (DBE volatile), 140 (HBM temperature).
Dennard scaling
1974 law: shrink all transistor dimensions by κ → 2× density, κ× speed, same power density. Broke ~2004 because leakage current couldn't scale with supply voltage. Clock speeds plateaued; industry pivoted to multi-core and domain-specific accelerators.
DRIE
Deep Reactive Ion Etching — plasma etch process (Bosch process) alternating SF₆ etch and C₄F₈ passivation cycles to create deep vertical holes for TSVs. Target: 5 µm diameter × 50 µm deep (10:1 aspect ratio).
ECC / ODECC
Error Correcting Code / On-Die ECC. HBM uses SECDED (single-bit correct, double-bit detect) on every 128-bit data burst with 8 check bits. Correctable errors (CE) are silent; uncorrectable errors (UE) signal data loss.
FEOL
Front End of Line — the fabrication phase where transistors and capacitors are built directly into the silicon. Includes well implants, gate oxidation, source/drain implants, and contact formation. Ends before any metal wiring layers.
FinFET / GAA
FinFET: transistor with vertical fin channel, gate on 3 sides — enables scaling from 22nm to ~5nm. Gate-All-Around (GAA) / nanosheet: horizontal silicon slabs, gate on all 4 sides — next generation below 3nm.
Flash Attention
Algorithm (Dao et al., 2022) computing transformer self-attention without materialising the N×N attention matrix in HBM. Tiles computation in on-chip SRAM. O(N) HBM accesses vs standard O(N²). 2–4× wall-clock speedup; enables long-context models.
GPU architecture
GPU: thousands of simple throughput-optimised CUDA cores for data-parallel computation, plus specialised tensor cores for matrix multiply-accumulate. H100: 132 SMs, 16,896 CUDA cores, 528 tensor cores, 80 GB HBM3 at 3.35 TB/s.
HBM bandwidth equation
Bandwidth = bus width × clock × transfers/clock. HBM3: 1024-bit bus × 6400 MT/s / 8 = 819 GB/s per stack. The wide bus is only physically possible because traces are 50 µm (on-stack) not 100 mm (PCB) — reducing capacitance 1000×.
Hugging Face
Central hub for open AI models (500K+ on Hub) and model infrastructure library (transformers). Unified API (AutoModel, AutoTokenizer, pipeline()) across hundreds of architectures. PEFT (LoRA), Datasets, Accelerate, TGI complete the ecosystem.
Hybrid bonding
Cu-to-Cu direct bonding without solder. Dies polished to <0.3 nm Ra, plasma-activated, bonded at room temperature, annealed at 150–200°C for Cu interdiffusion. Enables <10 µm pitch vs 55 µm for microbumps. Required for HBM4.
JAX
Google's functional AI framework. Four composable transforms: jit() (compile via XLA), grad() (differentiate), vmap() (vectorise), pmap() (parallelise). Used by DeepMind (AlphaFold, Gemini). Steeper learning curve than PyTorch; superior for problems needing composable transforms.
KGD
Known-Good Die — individual die fully tested and burn-in qualified before stacking. Essential because one bad die destroys the entire stack. Includes March algorithm cell tests, TSV continuity, retention test, and 125°C burn-in.
KV cache
Cached key/value tensors from prior tokens during autoregressive generation. Eliminates O(N²) recomputation. Memory cost: ~21 GB at 8K context for Llama 3 70B. Direct constraint on inference concurrency — HBM fills up with KV pages before GPU compute is exhausted.
LoRA / QLoRA
LoRA: fine-tune only low-rank additive matrices (A×B, r ≪ N); base model frozen. Reduces trainable params from 70B to ~4M for a 70B model. QLoRA adds 4-bit quantisation of the base, enabling 70B fine-tuning on one A100 80G. Standard for budget fine-tuning.
Low-k dielectric
Insulating material (k < 3.9) between metal wires to reduce parasitic capacitance and RC delay. Ultra-low-k achieves k ≈ 2.0 via controlled porosity — mechanically fragile.
Microbump
Small solder joint (Cu pillar + SnAg cap, ~55 µm pitch) connecting stacked dies in HBM. Thousands per die interface. Being replaced by hybrid bonding (Cu-Cu direct) for HBM4.
Mixed precision
Training in BF16 for forward/backward pass; FP32 master weights for updates. Halves activation memory; enables tensor cores. BF16 preferred over FP16: same exponent as FP32, no overflow risk under large gradient norms. FP8 (H100 Transformer Engine) is the frontier.
MoE
Mixture of Experts — feed-forward layers with N expert sub-networks; router selects K (typically 2) per token. Increases parameter count without proportional compute. GPT-4 (~1.76T params, 2/16 experts active), Mixtral 8×7B, DeepSeek V3 all use MoE.
NVML
NVIDIA Management Library — C/Python API for querying GPU health. Key HBM calls: nvmlDeviceGetMemoryInfo(), nvmlDeviceGetMemoryErrorCounter() for CE/UE counts, nvmlDeviceGetTemperature(), nvmlDeviceGetCurrentClocksThrottleReasons().
Page retirement
GPU driver mechanism permanently removing physical HBM pages from the usable address space after uncorrectable ECC errors. Check with nvidia-smi --query-retired-pages. Any DBE-retired page warrants scheduling GPU replacement.
PECVD
Plasma Enhanced Chemical Vapor Deposition — low-temperature dielectric deposition using plasma activation. Used for TSV oxide liner (SiO₂/SiN) that isolates copper from silicon.
PVD
Physical Vapor Deposition — sputtering process depositing thin metal films (TaN barrier, Cu seed) inside TSV holes. Ionised PVD (iPVD) improves bottom coverage at high aspect ratios.
PyTorch
Dominant AI research framework. Eager execution (operations run immediately, Python debugger works). Core abstractions: Tensor (n-dim array on CPU/GPU), autograd (automatic differentiation via computational graph), torch.nn (model building). PyTorch 2.0 adds torch.compile for JIT optimisation.
Quantisation
Reducing weight precision (FP16→INT8→INT4) to shrink HBM footprint. GPTQ/AWQ: 4-bit post-training quantisation. GGUF Q4_K_M: llama.cpp format. Llama 3 70B: 140 GB FP16 → ~40 GB Q4_K_M — fits on one H100 or consumer hardware.
RAG
Retrieval-Augmented Generation: embed query → retrieve similar document chunks from vector DB → inject into context → generate grounded response. Adds knowledge to LLMs without retraining. Quality depends on embedding model, chunk size strategy, and retrieval accuracy.
RDL
Redistribution Layer — thin-film copper wiring at 0.4–2 µm pitch on silicon interposers. Routes HBM's 1024-bit bus between die pads at densities impossible on organic substrates.
RLHF
Reinforcement Learning from Human Feedback. Three stages: (1) SFT on human-written good responses, (2) train reward model on human preference rankings, (3) PPO to maximise reward while penalising KL divergence from SFT model. Converts raw LLMs into helpful assistants. Used in ChatGPT, Claude, Gemini.
ROCm
AMD's open-source GPU compute stack. HIP (Heterogeneous Interface for Portability) compiles CUDA code for AMD GPUs with minimal changes. ROCm 6.x supports PyTorch, Flash Attention on MI300X. Remaining gap: profiling tools, third-party library coverage.
Scaling laws
Empirical power laws: test loss ∝ C^(−α) where C = training compute. Chinchilla (2022): optimal D ≈ 20×N params — GPT-3 was significantly undertrained. Doubling compute reliably reduces loss by a predictable factor. Whether they continue indefinitely at frontier scale is actively debated.
Self-attention
Attention(Q,K,V) = softmax(Q·Kᵀ/√d_k)·V. For each query position: compute attention score over all key positions, take weighted sum of values. O(N²) memory cost in sequence length N. Flash Attention reduces HBM accesses from O(N²) to O(N) via SRAM tiling.
Speculative decoding
Small draft model predicts K tokens ahead; large target model verifies all K in one pass. 2–3× throughput for predictable text (code, structured output) with identical quality. Less effective for creative/diverse generation where draft predictions are frequently wrong.
TCB
Thermal Compression Bonding — die stacking via heated bond head at 250–280°C. Forms Cu₃Sn/Cu₆Sn₅ intermetallic joints at microbump interfaces. Cycle time: 5–15 seconds per die.
Tensor cores
Specialised matrix multiply-accumulate units on NVIDIA GPUs. H100 4th-gen: computes 16×16×16 MMA in one instruction cycle. 528 tensor cores provide ~95% of peak FLOPS (989 TFLOPS FP16). Access via cuBLAS, cuDNN, or Triton.
Transformer
Neural network architecture (Vaswani et al., 2017) replacing recurrence with self-attention. Every position attends to every other simultaneously — fully parallelisable. Components: multi-head attention, feed-forward layers, layer norm, residual connections. Foundation of all major LLMs.
Triton
Python-based GPU kernel language (OpenAI) for writing custom GPU operations without raw CUDA. Auto-tiles for tensor cores. Flash Attention is implemented in Triton. Lowers barrier to writing high-performance custom kernels.
TSV
Through-Silicon Via — vertical copper conductor through a silicon die enabling die-to-die connections in HBM stacks. Dimensions: ~5 µm diameter × 50 µm deep. Requires DRIE etch, SiO₂ liner, TaN/Cu PVD, copper electroplating, and CMP.
Underfill / NCF
Underfill: epoxy injected between stacked dies to mechanically reinforce microbump joints. NCF (Non-Conductive Film): solid film laminated before bonding; compatible with sub-40 µm pitch where liquid underfill clogs.
Yield
Fraction of chips passing test. Murphy's model: Y ≈ e^(−D₀A). Exponential decrease with die area — a 2× larger die has roughly Y² yield. Chiplet integration improves yield by using smaller, higher-yielding dies.
